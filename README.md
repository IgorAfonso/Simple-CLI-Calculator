# 🧮 Simple CLI Calculator in C

A basic calculator that runs in the terminal, allowing users to perform simple arithmetic operations. This project is ideal for beginners looking to strengthen their fundamentals in C.

## 🔧 Features

- Addition
- Subtraction
- Multiplication
- Division (with zero-division validation)
- Text-based user interface

## 📁 Project Structure

simple-calculator/ ├── main.c └── calculator.h

## 🚀 How to Compile

```bash
gcc main.c -o calculator.exe
./calculator
